# Support

Choose the channel that matches the request:

| Request | Channel |
| --- | --- |
| Installation or configuration question | [GitHub Discussions Q&A](https://github.com/VickylastShao/deepseek-harness-desktop/discussions/categories/q-a) |
| Reproducible desktop-wrapper defect | [Bug report](https://github.com/VickylastShao/deepseek-harness-desktop/issues/new?template=bug.yml) |
| Desktop-host feature proposal | [Feature request](https://github.com/VickylastShao/deepseek-harness-desktop/issues/new?template=feature.yml) |
| Suspected vulnerability | [Private security report](SECURITY.md) |
| Model, plugin, session, tool, or Harness Web UI behavior | [Upstream DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) |

Before reporting a desktop defect, review the troubleshooting section in the
[user guide](docs/USER_GUIDE.md). Include the desktop version, operating system
and architecture, exact reproduction steps, and the smallest relevant log or
diagnostic excerpt.

Diagnostic bundles are size-bounded and pattern-redacted, but automated
redaction is not a guarantee. Review every file before publishing it. Do not
post credentials, private prompts, session data, or workspace files.

The project is maintained on a best-effort basis. Opening duplicate issues or
posting the same request across multiple channels does not accelerate review.
