Built for daily use

The desktop layer Harness was missing.

The upstream Web UI stays intact. The desktop app handles everything around it: startup, process health, updates, recovery, notifications, and support data.

01

Open and work

The installer includes the runtime. Harness starts in the background without exposing a console window.

02

Stay out of the way

Close to the tray, receive task-completion notifications, and reopen the same managed session.

03

Update without waiting

Harness and desktop updates are checked after launch, staged in the background, and activated on the next restart.

04

Diagnose in one step

The control center exposes runtime health and exports a bounded, redacted diagnostic bundle for support.

Clear project boundary

Upstream Harness inside. Community desktop host outside.

DeepSeek Harness supplies the agent runtime, plugin system, and Web UI. This repository supplies the Electron host, process lifecycle, staged updates, diagnostics, tray integration, and native installers.

This is an unofficial community project and is not a DeepSeek product.
